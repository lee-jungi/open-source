# FITGUIDE · 헬스 기구 & 운동 가이드 / 健身器械与训练指南

> **한눈에 보는 헬스 머신 & 프리웨이트 입문 가이드 웹앱 (한·중 이중언어 지원)**  
> **一目了然的健身器械与自由重量入门指南 Web 应用（支持韩中双语）**

---

## 1. 작품 소개 및 목적 / 作品简介与目的

- **작품명 / 作品名称**: `FITGUIDE` — 헬스 기구 & 운동 가이드 (健身器械与训练指南)
- **개발 목적 / 开发目的**:  
  헬스장을 처음 이용하는 입문자도 기본 매너부터 머신 세팅법, 프리웨이트 동작 자세까지 그림을 보며 직관적으로 배울 수 있도록 제작한 웹앱입니다. 모든 UI와 안내 문구를 **한국어와 중국어로 병기**하여 한국어·중국어 사용자 모두가 쉽게 이용할 수 있습니다.  
  本作品是一款面向健身房初学者的直观指南 Web 应用，帮助用户从健身房基本礼仪开始，通过动作图示轻松学习器械调节方法与自由重量标准动作。所有界面文字、提示与报错信息均采用**韩中双语并列**呈现。

---

## 2. 주요 기능 / 主要功能

1. **입장 화면 (Welcome / 欢迎入场页)**
   - 심플한 헬스 브랜드 로고와 서비스 소개, **`입장 / 入场`** 버튼 제공
   - 展示简洁品牌标识与核心亮点，点击 **`입장 / 入场`** 按钮进入
2. **헬스장 이용수칙 안내 (Gym Etiquette / 健身房使用须知)**
   - 기구 닦기, 원판·덤벨 정리, 기구 독점 금지, 안전핀 확인 등 6가지 기본 매너 안내
   - **우측 하단**에 배치된 **`다음 / 下一步`** 버튼으로 운동 선택 화면 이동
   - 介绍6项健身房基本礼仪规范，点击**右下角** **`다음 / 下一步`** 按钮进入训练动作列表
3. **정사각형 아이콘 카드 기반 운동 탐색 (Exercise Grid / 方形图标卡片选择页)**
   - **총 22종**의 운동(머신 11종 + 프리웨이트 11종)을 각 동작을 수행 중인 사람 일러스트(SVG)가 담긴 정사각형 카드로 배치
   - 유형별(`머신 / 器械`, `프리웨이트 / 自由重量`), 부위별(`가슴 / 胸部`, `등 / 背部`, `하체 / 腿部`, `어깨 / 肩部`, `팔 / 手臂`, `코어 / 核心`) 필터 및 한·중 실시간 검색 지원
   - 共收录 **22个训练动作**（器械11种 + 自由重量11种），每张方形卡片均配有对应动作图示（SVG），支持按类别、部位筛选及韩中双语实时搜索
4. **운동법 & 머신 사용법 상세 가이드 (Detail Guide / 动作与器械详情页)**
   - 카드 클릭 시 **타겟 근육**, **권장 세트**, **머신 세팅 및 준비**, **단계별 자세**, **호흡법**, **주의사항** 안내
   - 내장 **세트 휴식 타이머(60초/90초/120초)** 및 **`내 루틴 / 我的计划`** 담기 기능 지원
   - 点击卡片即可查看**目标肌群、推荐组数、器械调节与准备、动作步骤、呼吸方法、注意事项**，并内置**组间休息计时器**与**我的训练计划**收藏功能

## 4. 실행 방법 / 运行方法

별도의 패키지 설치나 빌드 과정 없이 바로 실행할 수 있습니다.  
无需安装依赖或构建，可直接运行：

### 방법 A. 브라우저로 바로 열기 / 方法 A：直接用浏览器打开
1. 저장소를 클론하거나 다운로드합니다. (`git clone https://github.com/lee-jungi/open-source.git`)
2. 폴더 내 `index.html` 파일을 더블 클릭하거나 Chrome / Edge 브라우저로 엽니다.

### 방법 B. 로컬 웹 서버로 실행하기 / 方法 B：通过本地服务器运行
```bash
# Python이 설치된 경우 / 若已安装 Python
python -m http.server 8080
# 브라우저에서 http://localhost:8080 접속 / 浏览器访问 http://localhost:8080
```
